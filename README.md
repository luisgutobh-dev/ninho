# Ninho

App da família para o dia a dia, no navegador e no celular (PWA mais um app Android de captura), com cinco módulos: Memória de gastos, Rotina, Agenda e lembretes, Consumo e Despensa. É também o case de estudo de system design do programa Expert autodidata.

Por enquanto este repositório guarda só a documentação. O código entra a partir do F1 M1.2.
